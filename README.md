# Reroom

Статический прототип сайта Reroom по переданному макету: главная страница приложения, локации, каталог, страница команды и 404.

## Страницы

- `index.html` — лендинг приложения с hero-блоком, схемой бронирования, картой и тарифами.
- `ourplaces.html` — локации, карточки станций и типы комнат.
- `catalog.html` — каталог фирменных товаров.
- `work.html` — страница найма с бонусами и формой заявки.
- `404.html` — ошибка в стилистике макета.

## Запуск

```bash
python3 -m http.server 8000
```

Открой <http://localhost:8000>.
